# МЕДИА ДЕТЕКТИВ — Жоғалған ақпараттың құпиясы

№17–18 практикалық сабаққа арналған қазақ тіліндегі интерактивті тергеу. React, TypeScript, Vite, Motion, Lucide. Барлық қаріп пен иллюстрация жергілікті жинаққа кіреді; сыртқы суреттер, тіркелгі және сервер қажет емес.

## Іске қосу

Node.js 22 немесе жаңарақ нұсқа:

```sh
npm install
npm run dev
```

Терминалда көрсетілген жергілікті мекенжайды ашыңыз. Өндірістік жинақ:

```sh
npm test
npm run build
npm run preview
```

`dist/` — дайын статикалық сайт. Оны HTTP сервер арқылы ашыңыз, `index.html` файлын тікелей ашу модульдерге байланысты қолдау таппайды.

## Сабақта қолдану

«Істі ашу» → топ атауы → тергеу тақтасы. Істер кезекпен ашылады. Құжаттарды оқытып, топтың дәлелдерін тыңдаңыз. Түсіндірмені талқылаудан кейін ашыңыз. «Дәлелді жинау · Істі аяқтау» келесі істі ашады. Сүйреудің баламасы: карточканы таңдаңыз, одан кейін қажетті орынға басыңыз.

Оң жақ жоғарғы бұрыштағы «Оқытушы» пультінде ерікті таймер, түсіндірме, дыбыс баптаулары, тақтаға оралу және қайта бастау бар. Таймер санайды, бірақ тапсырманы автоматты аяқтамайды. Жаңа ойында тыныш музыка алғашқы әрекеттен кейін қосылады. Бұрын сақталған дыбыс таңдауы сақталады. Толық экран батырмасын проекторда пайдаланыңыз. Соңғы сертификатты басып шығаруға немесе браузерден PDF ретінде сақтауға болады.

Балл: 1-іс — алғашқы бекітілген B таңдауы 20, өзге таңдау 0; 2-іс — екі тіркес 10 және екі нұсқадан дұрыс тақырыпты таңдауға тағы 10 (таңдау бір рет бағаланады); 3-іс — бірінші тексеруде 20, қатеден кейін 10; 4-іс — үш қате тіркестің бәрі табылғанда 20; 5-іс — 20, әр қате орналастыруға −2, ең азы 0. Баға бір рет бекітіледі. Оқытушы түсіндірмені бағалаудан бұрын да аша алады — бұл саналы түрде қолжетімді сабақ жүргізу құралы.

2-істе ештеңе жазылмайды: екі үрейлі тіркесті белгілегеннен кейін екі тақырып ашылады. Топ талқылайды, оқытушы нұсқаны таңдап растайды. 4-істе тек мәтін бар. Барлық тіркестер бастапқыда бірдей көрінеді және белгілене алады; жауаптар алдын ала көрсетілмейді. Қате таңдауда түсіндірме беріліп, қайта белгілеуге болады.

Прогресс, жауаптар және таймер мәні `localStorage` ішінде осы браузерде сақталады. Бет қайта ашылғанда таймер тоқтап тұрады. Қайта бастау тек растаудан кейін деректерді өшіреді. Оқу жаңалықтары ойдан шығарылған. Сертификат — сабақтағы жетістік белгісі, ресми біліктілік құжаты емес.

## Дыбыс пен қаріптер

Мәтін дауыстап оқылмайды. `public/audio/investigation-ambient.wav` — осы ойынға арнайы жасалған, сөзсіз 56 секундтық қайталанатын аспаптық әуен. Сыртқы сервистер мен бөгде жазбалар қолданылмайды. Музыканы қайта жасау көзі: `scripts/create_music.py` (Python + NumPy). Әуенді коммерциялық жоба құрамында пайдалануға болады.

Алғашқы басудан бұрын дыбыс ойнатылмайды. Жоғарғы дыбыс батырмасы музыка мен әсерлерді бірге өшіреді. «Оқытушы» пультіндегі «Фондық музыка» және «Батырма әсерлері» жүгірткілері олардың дыбысын бөлек реттейді. Музыканы 0%-ға қойып, әсерлерді қалдыруға болады. Батырма басу, қағаз ашу, растау, дұрыс/қате жауап және мұрағат ашу әсерлері Web Audio арқылы жасалады.

Noto Serif және Noto Sans қаріптерінің cyrillic және cyrillic-ext файлдары бірге қазақша Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І әріптерін қамтиды. Қаріптер `@fontsource` пакеттерінен жинақталады. Қозғалысты азайту жүйелік параметрі ескеріледі.

## Vercel / Netlify

- Репозиторийді импорттаңыз, түбір бумасы ретінде `media-detective` таңдаңыз (осы буманы бөлек жүктесеңіз, `.`).
- Build command: `npm run build`.
- Output / publish directory: `dist`.
- Серверлік айнымалылар қажет емес. Барлық экрандар бір URL ішінде, SPA қайта бағыттауы қажет емес.
- Netlify-де дайын `dist/` бумасын тікелей жүктеуге де болады.

## Құрылым

`src/content.ts` — оқу мәтіндері; `src/App.tsx` — экрандар, сақтау және басқару; `src/CaseTwo.tsx` және `src/CaseFour.tsx` — жаңартылған істер; `src/audio.ts` — музыка мен әсерлер; `src/style.css` — бейімделетін дизайн және CSS иллюстрациялар; `src/scoring.mjs` — бір реттік бағалау ережелері; `tests/` — бағалау тесттері.
